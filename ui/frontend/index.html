            Layer cache
            
            
                  
              Keeps decoded frame layers in memory so cards that share a frame
              skip decoding it again. A larger cache speeds up long batches and
              uses more memory, which can lower how many cards Automatic renders
              at once.
            
                  
          
                  
          
                  
            Image format
            
            
                  
              JPEG is written at quality 95, which is close to indistinguishable
              from the render at print size, and it encodes several times faster
              than PNG. An MPC Autofill project is always PNG.
            
                  
          
                  
          
                  
            PNG compression
            
            
                  
              Applies when the image format is PNG. Fast spends less time
              compressing each card, so batches finish sooner, but the files
              come out larger. The pixels are identical either way. File size
              matters most when uploading to MPC Autofill, which hides images
              over its size limit.
